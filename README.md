## 26 考试回忆版

### 考试题型

10道选择题(40分)，4道论述题(60分)

### 考点回忆

选择题：

1. h5 和原生层的交互方式（选择题）
2. Angular、Ionic、Cordova的基本特征(三道选择题)
3. ES6 和 CommenJS 的关系
4. TS和JS 的关系
5. npm 的基本知识（考点设置在package.json,选项混淆为plugin.xml）

> 选择题没有在选项上设置太多难度，一半题目都是3个扯淡选项1个看着就对的选项，只需要掌握每章的大致内容，就不会有太大问题

论述题：

1. native、h5、hybrid 三种开发方式的优缺点和适用场景
2. 以公共健康管理系统为例，论述目标分析、前后端设计、服务器设计等内容（也不是写实际代码，给出思路）
3. 时空移动数据的基本内容是什么，粒度指的是什么
4. 本课程学到的技术栈和工具，遇到的问题，应用前景

> 134都是基本题目，2可以参考第五章典型应用

## 复习提示

1. 不需要的内容:包括 H5、Java、python 等语法，各种 package.json ,plugin.xml 等格式文件的具体结构 ，各种框架的搭建命令行 以及课件/作业中的代码，都不需要掌握
2. 需要掌握的内容：各种框架的基本原理（ppt、笔记中的描述性内容），移动数据的基本内容 ，H5交互调用的方式（3+2）

> 复习两天差不多了，再多有点浪费
